# Denard refined colour system

## Positioning
Contemporary fashion — timeless style, curated quality, accessible elegance. Ivory-led, charcoal-structured, mint-accented, gold-refined.

## Palette
| Colour | Hex | Role |
|--------|-----|------|
| Soft Ivory | `#F6F1EA` | Main background (~70% with white) |
| White | `#FFFFFF` | Cards, forms, search |
| Rich Charcoal | `#1F1F1F` | Type, nav, footer, secondary buttons |
| Premium Mint | `#7FAF9B` | Soft brand moments, badges |
| Deep Mint | `#356B5A` | Primary CTAs, WhatsApp, active states |
| Champagne Gold | `#C6A46A` | Borders, dividers, logo accents (~3%) |
| Warm Taupe | `#B7A89A` | Secondary text, muted surfaces |
| Amber Fire | `#F39C12` | Sale / urgency only (~1%) |

## Buttons
- Primary: Deep Mint `#356B5A` → hover `#285244`
- Secondary: Charcoal `#1F1F1F` → hover `#333333`
- Soft: Premium Mint `#7FAF9B` → hover `#6A9B87`
- Outline: Gold border, ivory hover
- WhatsApp: Deep Mint (compact FAB)
